# 🧾 show-receipts (ภาษาไทย)

**ให้ AI พิสูจน์ก่อนบอกว่า "เสร็จแล้ว"**

เวลา AI coding agent บอกว่า *"แก้แล้วครับ เทสผ่านหมด"* show-receipts จะบังคับให้มันแนบ "ใบเสร็จ" (หลักฐาน) มาด้วย
ใช้ได้กับ Claude Code, Codex, Cursor, Gemini CLI และ agent ทุกตัวที่รันคำสั่ง shell ได้

## มันทำอะไร

1. **Hook บันทึกสิ่งที่รันจริง** ทุกคำสั่ง, exit code, hash ของ output และไฟล์ที่แก้ ลง `.receipts/ledger.jsonl`
   ซึ่ง harness เป็นคนเขียน ไม่ใช่ AI และมี hash chain ทำให้รู้ได้ถ้ามีใครแก้
2. **AI ต้องอ้างใบเสร็จ** หลังรันคำสั่ง AI จะเห็น `🧾 R12 recorded (exit 0)` และต้องเขียนในรายงานว่า `[R12]`
3. **Stop hook ตรวจรายงาน** ก่อนให้ AI จบงาน ถ้าคำอ้างไม่มีหลักฐานรองรับ จะส่งกลับไปแก้ 1 ครั้งพร้อมเหตุผล

## จับอะไรได้บ้าง

- บอกว่าเทสผ่าน แต่ไม่เคยรันเทส หรือรันแล้วไม่ผ่าน
- เทสผ่านแล้ว**แต่แก้โค้ดต่อ**หลังจากนั้น (ผลเทส stale)
- บอกว่าผ่าน 42 ข้อ แต่ output บอก `41 passed, 1 failed`
- อ้าง commit ที่ไม่มีอยู่จริง, อ้างว่าสร้างไฟล์ที่ไม่มีอยู่จริง, อ้างใบเสร็จปลอม
- เรียก API ที่ไม่มีจริงในเวอร์ชันที่ติดตั้ง (`check-symbol` พร้อมคำแนะนำชื่อที่ใกล้เคียง)
- ส่วนการบอกตรง ๆ ว่า "ยังไม่ได้ทดสอบ เพราะไม่มี DATABASE_URL" จะ**ไม่ถูกบล็อก** เพราะความซื่อสัตย์คือเป้าหมาย

ตัวตรวจเข้าใจคำอ้างทั้งภาษาอังกฤษและภาษาไทย (เช่น "เทสผ่าน", "แก้แล้ว", "เสร็จแล้ว")
